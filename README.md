This is a `scratch` branch. In this branch, Eclair is rewritten **from scratch**.

# Introduction
**Eclair** is an open-source audio player written in *C#*.
This player is gradually evolving and is aimed not only at listening to music, but also at beauty and ease of use.<br>
I will be glad to any help in the development of the project!

## BASS
**Eclair** uses the BASS audio library for audio playback.

## Why is Eclair open-source?
**Eclair** is my hobby, as is programming in general.
I support free software, and that's why **Eclair** is open-source.
I want to share my project's source code.
I enjoy developing this project and I don't think this player should be paid and closed source.<br>
And most likely no one would buy an audio player, let alone from someone [*noname*](https://github.com/NonExistPlayer).

## Supported audio formats
| Format | Name |
| :----: | :------------------------------------------------------ |
| `.mp3` | *MPEG-1 Audio Layer III* |
| `.aac` | *Advanced Audio Coding* |
| `.asf` | *Active Streaming Format or Advanced Streaming Format* |
| `.wma` | *Windows Media Audio* |
| `.ogg` | *Ogg* |
| `.flac`| *Free Lossless Audio Codec* |
| `.midi`| *MIDI* |
